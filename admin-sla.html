เกณฑ์ SLA / กฎ Repeat / Plant

หน้านี้ใช้กำหนด "กติกา" ที่ระบบจะใช้วัดเคสอุบัติเหตุ: (1) แต่ละขั้นควรเสร็จภายในกี่ชั่วโมง/วัน (SLA) และ (2) เมื่อไรถือว่าเหตุการณ์ "เกิดซ้ำ" (ISO 45001:2018 ข้อ 9.1 และ 10.2)

คู่มือเริ่มต้น (อ่านก่อนใช้งานครั้งแรก)

หน้านี้ใช้ทำอะไร และถ้าไม่ตั้งค่าจะเกิดอะไรขึ้น

  • ระบบไม่ได้ตั้งตัวเลขให้เพราะเกณฑ์เหล่านี้เป็นนโยบายของบริษัท ผู้รับผิดชอบต้องเป็นผู้กำหนด
  • ถ้ายังไม่ตั้ง ทุกช่องจะแสดง "ยังไม่กำหนดเกณฑ์" และระบบจะไม่นับว่าเคสใดเกินเวลาหรือเกิดซ้ำ หน้า Leading Indicator จะเป็น 0 ทั้งหมด ซึ่งเป็นเรื่องปกติของระบบที่ยังไม่ตั้งค่า
  • การตั้งเกณฑ์ไม่ได้เปลี่ยนข้อมูลเคสเดิม เกณฑ์ใหม่ใช้กับเคสที่เริ่มนับหลังตั้งเท่านั้น

ลำดับที่แนะนำสำหรับผู้เริ่มใช้

  1. สอบถามผู้รับผิดชอบนโยบาย (เช่น Head of SHE) ว่าบริษัทกำหนดเวลาแต่ละขั้นไว้เท่าไร
  2. แท็บ เกณฑ์ SLA: เลือก "ค่ากลาง" แล้วคลิกช่องของประเภทเหตุการณ์ที่ต้องการ ใส่เวลา แล้วบันทึก (ถ้ายังไม่แน่ใจ ใช้ปุ่ม "ใส่ค่าตัวอย่าง" เพื่อดูภาพรวมก่อน แต่ต้องแก้เป็นค่าจริงก่อนใช้งาน)
  3. แท็บ กฎ Repeat: ตั้ง N (กี่วัน) และ K (กี่เคส) ของแต่ละนิยาม
  4. แท็บ พื้นที่ต่อ Plant: เพิ่มรายการพื้นที่ในโรงงาน เพื่อให้ผู้รายงานเลือกได้
  5. แท็บ Priority site (Super admin เท่านั้น): ทำเครื่องหมาย Plant ที่ต้องการติดตามเป็นพิเศษ
  6. ตรวจผลที่หน้า Leading Indicator (เมนูผู้ดูแลระบบ)

คำศัพท์ที่พบในหน้านี้

SLA (Service Level Agreement)
เวลาสูงสุดที่ยอมรับได้ในแต่ละขั้นของเคส เช่น "เริ่มสอบสวนภายใน 24 ชั่วโมงหลังสร้างเคส"
ค่ากลาง (Central)
เกณฑ์ที่ใช้กับทุก Plant ตั้งได้เฉพาะ Super admin
Override ของ Plant
เกณฑ์เฉพาะของ Plant หนึ่ง ต้อง "เข้มเท่ากับหรือเข้มกว่า" ค่ากลาง (เวลาไม่นานกว่าค่ากลาง) และต้องมีค่ากลางก่อน
เตือนล่วงหน้า
ก่อนครบเวลาสูงสุดเท่านี้ ระบบจะแสดงสถานะ "ใกล้ครบเวลา" เพื่อให้เร่งดำเนินการ
เกินเวลา / ทันเวลา
เกินเวลา = ใช้เวลานานกว่าเกณฑ์ ทันเวลา = เสร็จภายในเกณฑ์
Root cause
สาเหตุรากเหง้าที่ผู้สอบสวนระบุในเคส (เช่น ไม่มีการตรวจสอบก่อนเริ่มงาน)
Repeat (เหตุการณ์เกิดซ้ำ)
เหตุการณ์ที่เกิดซ้ำตามเงื่อนไข N และ K ด้านล่าง ระบบเพียง "เสนอ" ผู้สอบสวนเป็นผู้ยืนยันหรือปฏิเสธ
N (วัน) และ K (เคส)
N = ช่วงเวลาที่ย้อนดู, K = จำนวนเคสขั้นต่ำที่ถือว่าซ้ำ เช่น N=90, K=3 คือเกิด 3 เคสขึ้นไปใน 90 วัน
Priority site
Plant ที่ให้ความสำคัญเป็นพิเศษ ใช้เพื่อกรองดูใน Leading Indicator เท่านั้น ไม่ได้เปลี่ยนสิทธิ์หรือเกณฑ์ของ Plant
ทำอย่างไร: (1) เลือก "ขอบเขต" ด้านล่าง ค่ากลางใช้กับทุก Plant หรือเลือก Plant เพื่อตั้งเกณฑ์เฉพาะ (2) คลิกช่องในตาราง ซึ่งแถวคือประเภทเหตุการณ์ และคอลัมน์คือขั้นของเคส (3) กรอกเวลาสูงสุด เวลาเตือนล่วงหน้า และเหตุผล แล้วกด "บันทึกเกณฑ์"
ขั้นทั้ง 5 คือ: ส่ง Flash report (หลังเกิดเหตุ), เริ่มสอบสวน, สอบสวนเสร็จ, ปิด Action ครบ, ปิดเคส ช่องที่เขียนว่า "ยังไม่กำหนดเกณฑ์" แปลว่ายังไม่มีใครตั้งค่า (คลิกเพื่อตั้งได้)

ยังไม่มีประเภทเหตุการณ์ที่ใช้งานอยู่

นับเป็นเวลาตามนาฬิกาจริง (ไม่หักวันหยุด) เกณฑ์ใหม่ไม่ย้อนกระทบเคสที่เริ่มนับไปแล้ว ค่า override ของ Plant ต้องเข้มกว่าหรือเท่ากับค่ากลาง

เป็นตัวอย่างเพื่อให้เห็นภาพเท่านั้น ไม่ใช่นโยบายบริษัท ปุ่มนี้แค่กรอกช่องให้ ยังไม่บันทึก แก้เป็นค่าจริงและใส่เหตุผลก่อนกดบันทึก
ทำอย่างไร: เลือก "นิยาม" ที่ต้องการ กรอก N (ช่วงกี่วันที่ย้อนดู) และ K (จำนวนเคสขั้นต่ำ) ใส่เหตุผล แล้วกด "บันทึกกฎ"
ตัวอย่างการทำงาน: ตั้ง Repeat root cause เป็น N=90, K=3 → ถ้า root cause เดียวกันเกิดใน Plant เดียวกัน 3 เคสขึ้นไปภายใน 90 วัน ระบบจะแจ้งผู้สอบสวนในเคสนั้นว่า "พบเหตุการณ์ที่อาจเกิดซ้ำ" ให้ยืนยันหรือปฏิเสธ ระบบไม่ตัดสินแทนคน

นิยามการเกิดซ้ำ

  • Repeat root cause: root cause เดียวกัน ใน Plant เดียวกัน ภายใน N วัน รวมอย่างน้อย K เคส
  • Repeat case: ประเภทเหตุการณ์และพื้นที่เดียวกัน ภายใน N วัน รวมอย่างน้อย K เคส
  • Repeat after closure: root cause เดิมเกิดอีกภายใน N วันหลังปิด Action (Action ไม่ได้ผล)
นิยามขอบเขตN (วัน)K (เคส)สถานะเหตุผล

ยังไม่ได้ตั้งกฎ ระบบจึงยังไม่ตรวจจับเหตุการณ์เกิดซ้ำ ให้กรอกฟอร์ม "ตั้ง / แก้ไขกฎ" ด้านล่างเพื่อเริ่มตั้งค่า

ตั้ง / แก้ไขกฎ

ค่า override ของ Plant ต้อง "ไวเท่ากันหรือไวกว่า" ค่ากลาง (N ไม่น้อยกว่า, K ไม่มากกว่า, ปิดการตรวจไม่ได้) ผู้สอบสวนยืนยัน/ปฏิเสธรายเคสได้เอง

เป็นตัวอย่างเพื่อให้เห็นภาพเท่านั้น ไม่ใช่นโยบายบริษัท ยังไม่บันทึกจนกว่าจะกด "บันทึกกฎ"
หน้านี้ใช้ทำอะไร: ทำเครื่องหมาย ★ ให้ Plant ที่ต้องการติดตามเป็นพิเศษ เพื่อให้หน้า Leading Indicator เลือกดู "เฉพาะ Priority site" ได้ (ไม่ได้เปลี่ยนสิทธิ์หรือเกณฑ์ของ Plant)
ทำอย่างไร: กดปุ่มในแถวของ Plant → ใส่เหตุผล → กด "ยืนยัน" ตั้งได้เฉพาะ Super admin และยังไม่มีรายชื่อตั้งต้น ให้ผู้บริหารหรือ Head of SHE กำหนดว่า Plant ใดสำคัญ
PlantBusiness unitสถานะ

หน้านี้ใช้ทำอะไร: กำหนดรายการ "พื้นที่" ในแต่ละโรงงาน เช่น คลังสินค้า, ไลน์ผลิต 1, ห้องหม้อไอน้ำ ผู้รายงานจะเลือกพื้นที่จากรายการนี้ตอนแจ้งเหตุ และระบบใช้ตรวจ Repeat case (เหตุที่เกิดที่เดียวกัน)
ทำอย่างไร: (1) เลือก Plant (2) กรอกรหัสสั้น ๆ ภาษาอังกฤษ/ตัวเลข เช่น WH01 ชื่อไทย และชื่ออังกฤษ (ถ้ามี) (3) ใส่เหตุผล แล้วกด "บันทึก" ยังไม่มีพื้นที่ตั้งต้น ต้องเพิ่มเองทีละ Plant
