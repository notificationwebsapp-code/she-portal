เกณฑ์ SLA / กฎ Repeat / Plant

กำหนดเกณฑ์เวลา (ISO 45001:2018 ข้อ 9.1) และเงื่อนไขตรวจจับเหตุการณ์เกิดซ้ำ (ข้อ 10.2) ระบบไม่มีค่าเริ่มต้น: ขั้นที่ยังไม่ตั้งเกณฑ์จะแสดงว่า "ยังไม่กำหนดเกณฑ์"

ยังไม่มีประเภทเหตุการณ์ที่ใช้งานอยู่

นับเป็นเวลาตามนาฬิกาจริง (ไม่หักวันหยุด) เกณฑ์ใหม่ไม่ย้อนกระทบเคสที่เริ่มนับไปแล้ว ค่า override ของ Plant ต้องเข้มกว่าหรือเท่ากับค่ากลาง

นิยามการเกิดซ้ำ

  • Repeat root cause: root cause เดียวกัน ใน Plant เดียวกัน ภายใน N วัน รวมอย่างน้อย K เคส
  • Repeat case: ประเภทเหตุการณ์และพื้นที่เดียวกัน ภายใน N วัน รวมอย่างน้อย K เคส
  • Repeat after closure: root cause เดิมเกิดอีกภายใน N วันหลังปิด Action (Action ไม่ได้ผล)
นิยามขอบเขตN (วัน)K (เคส)สถานะเหตุผล

ยังไม่ได้ตั้งกฎ ระบบจึงยังไม่ตรวจจับเหตุการณ์เกิดซ้ำ

ตั้ง / แก้ไขกฎ

ค่า override ของ Plant ต้อง "ไวเท่ากันหรือไวกว่า" ค่ากลาง (N ไม่น้อยกว่า, K ไม่มากกว่า, ปิดการตรวจไม่ได้) ผู้สอบสวนยืนยัน/ปฏิเสธรายเคสได้เอง

ธง Priority site ใช้กรองมุมมอง Dashboard (ตั้งได้เฉพาะ Super admin) ไม่มีรายชื่อตั้งต้น
