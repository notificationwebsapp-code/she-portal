ประเภทเหตุการณ์ / ความรุนแรง / ผู้เกี่ยวข้อง

กำหนดตัวเลือกของ "รายงานอุบัติเหตุ" ทั้งหมดด้วยตัวเอง ไม่ต้องแก้โค้ด รายงานแต่ละฉบับจะถูกจัดกลุ่มจาก 3 แกนที่แยกจากกัน

1) ประเภทเหตุการณ์ (ต้นไม้)

"เกิดอะไรขึ้น" แบ่งเป็นหมวดใหญ่ → หมวดย่อย ได้หลายระดับ (แนะนำไม่เกิน 4 ระดับ) เช่น ไฟไหม้ → ไฟฟ้า → ตู้ควบคุม

2) ความรุนแรง (Pyramid)

"รุนแรงแค่ไหน" เรียงจากรุนแรงที่สุดไปน้อยที่สุด ใช้วาด Pyramid ใน Dashboard เช่น FAT, LTI, RWC, MTC, FAC, PD, NEAR

3) ผู้เกี่ยวข้อง

"เกิดกับใคร" เช่น พนักงาน ผู้รับเหมา ซัพพลายเออร์ แยกจากประเภท เพื่อกรองและเทียบสถิติได้

ถ้าไม่ตั้งค่า: ฟอร์มรายงานจะไม่มีตัวเลือกให้เลือก และ Dashboard จัดกลุ่มไม่ได้ ไม่มีการลบข้อมูล: ถ้าไม่ใช้แล้วให้ "ปิดใช้งาน" รายงานเดิมยังอ้างอิงถูกต้อง รหัส (Code) แก้ไม่ได้หลังสร้าง

ประเภทเหตุการณ์ (ต้นไม้)

กด "+ ลูก" เพื่อเพิ่มหัวข้อย่อยใต้รายการนั้น หรือใช้ฟอร์มด้านล่างเพิ่มหัวข้อระดับบนสุด "ผู้รายงานเลือกได้" = ติ๊กเมื่อเป็นหัวข้อปลายทางที่เลือกในฟอร์มได้ ไม่ติ๊กเมื่อเป็นหัวข้อกลุ่มที่ใช้จัดหมวดเท่านั้น

ชื่อ (ไทย / English)รหัสระดับผู้รายงานเลือกได้สถานะจำนวนรายงานการทำงาน

ความรุนแรง (Pyramid)

เรียงจากรุนแรงที่สุดอยู่บน ใช้ปุ่ม ▲ ▼ ปรับลำดับ ชื่อและคำอธิบายให้ตั้งตามนิยามของบริษัท ระบบไม่ตัดสินแทน (เช่น นิยาม LTI / RWC / MTC อาจต่างจากเกณฑ์บันทึกกรณีของ OSHA 29 CFR 1904.7)

ลำดับรหัสชื่อ (ไทย / English)คำอธิบายร้ายแรงสถานะจำนวนรายงานการทำงาน

ผู้เกี่ยวข้อง

ผู้ที่เกี่ยวข้องกับเหตุการณ์ เช่น พนักงาน ผู้รับเหมา ซัพพลายเออร์ เพิ่มประเภทอื่นได้ (เช่น ผู้มาติดต่อ) รายงานเดิมที่ยังไม่ระบุจะแสดงเป็น "ไม่ระบุ"
